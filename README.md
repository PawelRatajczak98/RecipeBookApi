# RecipeBook

**RecipeBook** to aplikacja webowa umożliwiająca użytkownikom zarządzanie przepisami kulinarnymi, posiadanymi składnikami i budżetem.

## Technologie

- C# (ASP.NET Core 8)
- ASP.Net Identity
- Entity Framework Core
- MS SQL
- LINQ
- JWT (JSON Web Token)
- xUnit
- TestContainers + Docker

## Funkcje

- Rejestracja / logowanie z JWT
- Dodawanie i przeglądanie przepisów
- Zarządzanie posiadanymi produktami (dodawanie, edycja ilości, usuwanie)
- Wyszukiwanie dostępnych do przygotowania przepisów na podstawie posiadanych produktów
- Wyszukiwanie przepisów znajdujących się w posiadanym budżecie
